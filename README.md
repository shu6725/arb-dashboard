# Arb Dashboard

This project implements an arbitrage dashboard that retrieves and displays order book data from various exchanges, converts USD prices to JPY, and detects arbitrage opportunities. The dashboard is built using Python and Plotly Dash.

## Requirements

- **Python:** 3.11.6  
- **Dependencies:** See [`requirements.txt`](requirements.txt) for a complete list of required packages.
